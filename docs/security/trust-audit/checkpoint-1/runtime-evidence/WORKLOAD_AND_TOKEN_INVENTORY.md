- 114/116 workloads run under the namespace `default` ServiceAccount. Only `estate-health-watch` (a CronJob) has a dedicated SA.
- No per-service Kubernetes ServiceAccount => no workload identity distinction at the K8s layer.
- No Keycloak *service* clients per workload were found in runtime env except the four shared clients below.
