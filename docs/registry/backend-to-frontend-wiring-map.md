## Open Wiring Gaps

- Citizen `ConditionsSection` and provider discovery screens remain TODO/local placeholders and need API-backed implementation.
- SOAP notes save flow in provider tooling requires persistence endpoint wiring.
- Public-health fixtures are no longer rendered in disabled tabs, but fixture artifacts should remain isolated from any future production route imports.
- Teleconsult real-time media/signaling backend remains intentionally unavailable; execution paths remain explicitly blocked to avoid synthetic success.
- `/reports` national aggregate tab now shows governed warehouse KPI cards (gold stats) on DHIS2 while still rendering explicit unavailable states for tabs without governed feeds; no synthetic KPI values are shown.
