## 9. What runs on push

- Full `ci.yml` for `claude/**` branches.
- `deprecated-surface-guard.yml` when relevant paths change.
- **`preview-pipeline-gates`** only on push to `claude/staging-ux-orchestration-remediation-Yypyl`.
- **Does not** auto-run `deploy-preview.yml` or SSH deploy.
