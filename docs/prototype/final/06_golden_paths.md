# 06 — Golden Paths

> This document was provided inline during the Impilo vNext build session.

Six golden path scripts define the critical user journeys through the system. Path A covers Email Login, Path B covers Provider ID with Biometric authentication, Path C traces the clinical workflow from Queue through Encounter to Close, Path D follows the Admin pathway into TSHEPO governance, Path E exercises the Marketplace integration flow, and Path F walks through the Registry data management workflow. Each path is scripted step-by-step with expected UI states and data outcomes.
