# 00 — Executive Summary

> This document was provided inline during the Impilo vNext build session.

Impilo vNext is a Health Information Exchange (HIE) and Digital Health Platform prototype. The system is organized into 15 zones with 4 authentication pathways and 39 kernel admin routes. The auth model follows a hierarchical tenancy structure: Auth to Facility to Workspace to Shift. The UI is built around 4 layout variants and 11 sidebar contexts, using a design system based on shadcn/ui, Tailwind CSS, Lucide icons, and Framer Motion for animations.
