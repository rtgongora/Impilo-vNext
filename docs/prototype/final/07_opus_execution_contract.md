# 07 — Opus Execution Contract

> This document was provided inline during the Impilo vNext build session.

The execution contract defines 11 implementation phases with strict no-deviation rules. A verification checklist accompanies each phase to confirm completion before advancing. The implementation order progresses from foundation infrastructure through core layouts, authentication, navigation, and data layer, culminating in specialized pages and domain-specific features. Each phase specifies its inputs, outputs, and acceptance criteria.
