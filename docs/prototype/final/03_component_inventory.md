# 03 — Component Inventory

> This document was provided inline during the Impilo vNext build session.

The component inventory catalogs all shared and domain-specific UI components. Layout components include AppLayout, AppSidebar, AppHeader, EHRLayout, TopBar, and EncounterMenu. Additional component groups cover authentication flows, home/dashboard views, EHR clinical interfaces, patient search, navigation shells, notification systems, and emergency workflows. Each component entry defines its props interface, internal state, and composition relationships.
