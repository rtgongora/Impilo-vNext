# Person Journey

The person journey converts a health need into guided, trusted, accessible, continuous care.

## Canonical Stages

Find Care -> Identify Me -> Select Service -> Confirm Cost/Coverage/Exemption -> Pay Upfront (where required) -> Access Service -> Prepare for Care -> Receive Care -> Settle Additional Charges/Claims -> Know What Happened -> Continue Care -> Give Feedback.

## Rules

- A person should never need to understand internal service boundaries.
- Payment variation is policy-aware: pre-service, post-service, exempt, subsidized, claim-based, deferred.
- Emergency care is never blocked by pre-service payment gate.
- Nompilo should explain what is happening and what to do next in plain language.
- Accessibility support (audio, keyboard, high contrast, low-bandwidth) must be available where relevant.
