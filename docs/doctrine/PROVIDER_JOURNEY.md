# Provider Journey

The provider journey reduces cognitive burden and makes the next safe action obvious while preserving professional judgement.

## Canonical Stages

Start Duty -> See My Work -> Open Client Context -> Confirm Service Access Status -> Prepare/Triage/Screen -> Deliver Care -> Order Actions -> Complete Transaction -> Confirm Charges/Claims/Follow-Up -> Continue Responsibility.

## Rules

- Provider context must include role, facility, workspace, and trust basis.
- The experience layer must surface blockers (payment gate, missing consent, sync failure, documentation gaps).
- Nompilo provider assist can explain blockers and missing fields but cannot override clinical judgement.
- Fundo competency links should be surfaced for workflow changes or repeated provider friction.
