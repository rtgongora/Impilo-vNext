# Nompilo Accessibility and Omnichannel Feedback

Nompilo must support inclusive use across client and provider workflows.

## Accessibility Capabilities

- simple language;
- audio/read-aloud guidance;
- voice input (where safe and appropriate);
- keyboard-first interaction;
- screen-reader friendly wording;
- large text, high contrast, reduced motion;
- caregiver/proxy assistance;
- low-bandwidth support.

## Feedback Channels

- in-app;
- web portal;
- SMS;
- WhatsApp-style messaging;
- USSD;
- kiosk;
- call centre;
- email;
- CHW-assisted;
- facility feedback desk.

## Feedback Data Linkage

Feedback should carry `transaction_id`, facility/service context, journey stage, actor type, issue category, sentiment, accessibility signal, and resolution state.
