# Nompilo Fundo Learning Assistant

## Role

Nompilo within Fundo supports:

- module explanation and simplification
- refreshers
- quiz generation and support
- competency-aligned recommendations
- workflow-linked learning prompts

## Safety

- Nompilo does not alter assessment scoring authority.
- Fundo remains source of truth for modules, competency records, and assessments.
- Learning suggestions are contextual and role-aware.

## Integration Points

- Fundo module metadata
- competency and role matrix
- provider workflow context from active transaction
