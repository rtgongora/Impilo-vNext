# Core Transaction Plane Map

The Core Transaction is the operational spine across the canonical seven planes.

## Plane Binding

1. **trust**: actor authz, purpose-of-use, consent, device/session risk, audit basis (Tshepo, Mvumo, Tshepo Audit).
2. **registry**: person/provider/facility/service/site/terminology resolution (Vito, Varapi, Tuso, Msika, Zibo, Indawo, Ubomi).
3. **clinical**: encounter, orders, results, pharmacy, SHR contribution (PCT/OROS/Butano/Pharmacy).
4. **data**: indicators, surveillance, quality, reporting, intelligence (NDR, DWH, reporting, surveillance).
5. **integration**: notifications, adapters, jobs, offline sync, federation (integration hub, notification, offline services, adapters).
6. **experience**: One UI Shell and Experience BFF orchestration surfaces.
7. **enterprise**: costing, billing, claims, payment, remittance, reconciliation (Costa, MusheX, coverage, GL).

## Rule

The Core Transaction does not replace plane ownership; it coordinates plane interactions while preserving sovereign truth boundaries.
