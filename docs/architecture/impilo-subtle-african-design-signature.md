# Impilo Subtle African Design Signature

## Intent

Express African warmth and identity with restraint, not decorative overload.

## Signature Elements Implemented

1. **Color rhythm**
   - Green-led interaction model with yellow/red used as controlled accents.
   - Charcoal-led text contrast for trust and seriousness.

2. **Subtle pattern accents**
   - Added low-opacity accent utility (`.impilo-subtle-african-accent`) for shell and section backgrounds.
   - Uses lightweight radial + linear overlays, not heavy motif backgrounds.

3. **Human warmth through spacing**
   - Rounded card clusters and generous spacing in shell, page wrappers, and kiosk.

4. **Context-sensitive expression**
   - Clinical and provider surfaces remain calm.
   - Assistant/wellness/citizen-like surfaces use slightly warmer tone shifts.

5. **Language readiness**
   - UI remains compatible with longer strings and future multilingual expansion.
   - No brittle fixed-width decorative text treatments introduced.

## Non-Goals Enforced

- No folkloric or tourist motifs.
- No loud flag-color backgrounds.
- No decorative red/yellow blocks for non-semantic purposes.
- No reduction in clinical readability.
