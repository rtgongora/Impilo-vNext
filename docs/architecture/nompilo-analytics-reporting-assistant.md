# Nompilo Analytics Reporting Assistant

## Scope

Nompilo can answer authorised data questions and assist with:

- dashboard generation
- chart/table generation
- report drafting
- trend comparison
- briefing summaries
- data quality issue highlighting

## Governance

- Data access follows role and policy controls from the Data Plane.
- Generated narrative is clearly tagged as generated explanation.
- Raw metrics and indicators must reference authoritative source datasets.

## UX Outputs

- Dashboard assistant panel
- Report builder panel
- Login briefing card for managers and programme users
- Follow-up question suggestions for iterative analysis
