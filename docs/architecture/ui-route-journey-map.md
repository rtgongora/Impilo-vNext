# UI Route Journey Map

## Canonical Mapping Source

- `ui/one-ui-shell/src/lib/ui-route-journey-map.ts`

## Route Groups

- Person Journey: citizen/client/discovery/wellness/wallet/telemedicine and related self-service surfaces.
- Provider Journey: provider workspace/clinical/queue/ehr/lab/pharmacy/learning/guidance.
- Platform Journey: operations/monitoring/reports/finance/enterprise/admin and governance routes.
- Cross-cutting: ask/search/support/core-transaction/settings/auth/home/shell.

## Role-Aware Navigation Projection

- Client: Home, Find Care, My Visit, Appointments, Results, Medicines, Payments, Wellness, Feedback, Ask Nompilo.
- Provider: Start Duty, My Work, Queues, Patient Context, Encounters, Orders, Results, Fundo, Support, Ask Nompilo.
- Manager: Command Centre, Transactions, Facilities, Services, Providers, Queues, Payments, Claims, Reports, Audit, Sync, Support, Ask Nompilo.
