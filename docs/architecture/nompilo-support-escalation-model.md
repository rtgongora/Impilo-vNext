# Nompilo Support Escalation Model

## Objectives

- Explain issues and suggest self-service fixes.
- Create contextual support tickets with transaction references.
- Route to human support when policy or confidence requires.
- Track and close support loop with feedback collection.

## Escalation Flow

1. Detect unresolved or unsafe command outcome.
2. Present self-service guidance.
3. Offer governed handoff options.
4. Create support ticket with minimal required context.
5. Expose status and request post-resolution feedback.

## Guardrails

- Nompilo does not bypass support policies.
- Nompilo does not expose restricted clinical or financial data in tickets.
- Confidence threshold and access status can force human handoff mode.
