# Transaction Context Panel

## Purpose

Provide a reusable transaction snapshot panel that aligns person/provider/platform journey stages with current state, trust, payment, sync, blockers, and source-of-truth constraints.

## Implementation

- Component: `TransactionContextPanel` in `ui/one-ui-shell/src/features/core-transaction/components.tsx`.
- Included in `CoreTransactionShell`.

## Displayed Context

- Transaction type and state.
- Person, provider, and platform current stages.
- Trust and consent/access status.
- Payment/access status.
- Offline/sync status.
- Current blockers.
- Source-of-truth reminder.
