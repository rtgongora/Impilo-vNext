# Core Transaction Service Ownership

## Registry and Identity

- **Vito**: client identity and reconciliation.
- **Varapi**: provider identity, role eligibility, standing.
- **Tuso**: facility/workspace context.
- **Zibo**: terminology authority.
- **Msika**: service/product catalog authority.
- **Indawo/Ubomi**: public-health site and civil-event context.

## Trust and Governance

- **Tshepo + Mvumo + Tshepo Audit**: authz, consent, purpose-of-use, audit evidence.

## Clinical and Continuity

- **PCT/OROS/Pharmacy/Butano**: encounter, orders/results, dispense, SHR contribution.

## Enterprise and Financial

- **Costa**: costing and billability.
- **MusheX**: payment/remittance/claims settlement rails.

## Orchestration and UX

- **Msika Flow/workflow/integration services**: execution orchestration.
- **Fundo (learning-service/workforce context)**: competency and readiness support for provider-side execution.
- **Experience BFF + One UI Shell + Nompilo guidance**: user-facing composition and workflow guidance.

## Rule

No feature may move ownership away from sovereign services; composition is allowed, domain truth duplication is not.
